## 📐 Technical Specifications

### Card Thumbnails
- **Format:** PNG with transparency
- **Resolution:** 512x512px (optimized for card UI)
- **Naming:** EDX[1-102]_[Description]_card.png
- **Use Case:** Game event cards, decision points

### Crisis Characters
- **Format:** PNG with alpha channel
- **Resolution:** 512x512px
- **Naming:** Crisis_[Description].png
- **Use Case:** NPC portraits, antagonists, stakeholders

### Logo Variations
- **Format:** PNG
- **Resolution:** 1024x1024px (high quality)
- **Naming:** Logo_variation_[Style].png
- **Use Case:** Branding, menus, promotional materials

### Scene Backgrounds
- **Format:** PNG
- **Resolution:** 1920x1080px (16:9 widescreen)
- **Naming:** BG_[Location]_[Mood].png or [Description]_scene.png
- **Use Case:** Game environments, cutscenes, UI backgrounds
